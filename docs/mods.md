# 简单特效模组

首版模组是 UTF-8 JSON 文件，文件大小最多 16 KB。导入后保存到用户应用数据目录。每个模组 ID 必须唯一。

`hammer` 使用抬锤蓄力、加速挥落、命中停顿和回弹，附带金属块面、冲击环、Hakai 裂纹及碎屑。`burst` 使用收缩蓄能、放射爆闪、双层冲击波和弹道拖尾。`hits` 控制完整攻击动作的重复次数，`duration` 控制总播放时间。

`glass` 移植 Hakai 的放射裂纹、连接裂缝和明暗碎片面，附带本项目的冲击与飞散碎屑。`phaser` 移植 Hakai 的熔融边缘、渐变爆心和放射灼痕，支持颜色变体。二者通过同一绘制入口在 Windows 和 macOS 使用，复制内置 `glass.json` 或 `phaser.json` 并更换 ID 即可制作自己的参数模组。

## 示例

```json
{
  "version": 1,
  "id": "mint-strike",
  "name": "薄荷重击",
  "renderer": "hammer",
  "color": "#63D8C4",
  "duration": 1.8,
  "hits": 3,
  "size": 150
}
```

## 字段

| 字段 | 规则 |
| --- | --- |
| version | 固定为 1 |
| id | 1～40 个字符，以小写字母开头，后续可使用小写字母、数字、下划线或连字符 |
| name | 1～40 个字符的显示名称 |
| renderer | hammer、burst、ring、glass 或 phaser |
| color | 六位 RGB 十六进制颜色 |
| duration | 0.4～5 秒 |
| hits | 1～5 次 |
| size | 60～300 个逻辑像素的基准大小 |

设置面板的全局大小以 130 为基准缩放模组大小。例如模组 size 为 150，面板大小为 260，实际尺寸为 300。

在源码中增加绘制器时，需要更新 `effects.py` 的校验与绘制分支，并补充对应测试。覆盖层统一负责目标位置、时序和资源清理。首版绘制全部使用程序生成图形。

## 导入与修改

1. 复制 `src/crit_strike/mods/` 下任一文件。
2. 更改 ID、名称及效果参数。
3. 在应用中点击“导入模组”。
4. 为目标选择新效果，点击“预览效果”。

相同 ID 的模组会被拒绝导入。需要制作变体时使用新的 ID。
