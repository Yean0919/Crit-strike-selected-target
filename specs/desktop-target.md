# 全桌面头像打击首版

## 范围

Windows 10 2004 及以上版本和 Windows 11。检测所有显示器当前可见内容，支持多个静态头像模板。模板匹配不区分使用相同头像的人。隐藏、最小化、受保护画面不在屏幕检测范围内。

## 行为

1. 用户导入图片、裁剪为方形模板，为目标设置名称、匹配阈值和效果。
2. 用户主动启动自动检测。每个匹配位置独立跟踪，稳定至少三秒后触发。
3. 五个物理像素内的抖动保持计时，超出后从新位置重新计时。漏检容错以 0.6 秒为基线，根据实际扫描周期调整。漏检帧不得触发。
4. 持续停留只触发一次。明显移动或持续消失后重新计时。模板停用及暂停清除跟踪状态。
5. 自动模式只在内存处理截图。覆盖层从 Windows 捕获中排除，失败时暂停自动检测并显示状态。
6. 特效播放时鼠标穿透。手动选点时显示可取消的选择层，左键播放，右键或 Esc 取消。
7. 同时最多四个特效，显示器布局变化时暂停并要求重新启动检测。
8. 图片、配置及导入模组存入用户应用数据目录，禁止将真实用户模板、桌面截图及配置加入仓库或构建包。
9. 模组通过 JSON 配置内置 hammer、burst、ring 绘制器，支持颜色、大小、时长及次数。错误模组给出明确错误。

## 验收

- 合成测试验证多个缩放尺寸、多个位置、无目标、近似模板和圆角显示。
- 使用可控时钟验证三秒前不触发、到时触发一次、移动重计时、短暂漏检及持续消失。
- 验证负坐标和混合缩放的物理到逻辑坐标映射。
- 使用人工生成头像的真实桌面测试验证截图、检测、计时和覆盖层播放链路。
- 所有自动化测试通过，打包产物启动成功，待提交文件及构建产物隐私扫描通过。
- 记录测试环境实际覆盖的显示器组合和性能，未验证环境如实列出。
