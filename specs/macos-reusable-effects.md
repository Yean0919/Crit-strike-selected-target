# macOS 与可复用打击效果

## 范围

在现有自动识别、三秒稳定触发、手动选点和 JSON 模组入口中接入 Hakai 的 MIT 授权程序化效果。增加 macOS 14 及以上版本的源码运行与本机架构应用构建入口。

## 验收

- 移植 Hakai 的玻璃放射裂纹、连接裂缝、碎片明暗面和能量命中算法，保留来源提交、原始许可证和改动说明。
- 新增 `glass`、`phaser` 绘制器，原有三个绘制器及已保存模组继续可用。新效果支持颜色、大小、时长、次数及现有所有触发入口。
- 动画可重复绘制、结束清空，几何缓存有上限，截图与特效均在本地处理。
- macOS 通过 AppKit 配置全屏透明鼠标穿透窗口，支持所有桌面 Space。ScreenCaptureKit 排除自身应用，避免特效干扰检测。
- Retina 屏幕按每屏逻辑坐标和输出像素单独换算，显示器变化暂停检测。
- 屏幕录制权限不足时显示可操作的提示，手动特效继续可用。全局按键监听权限不足时提示使用窗口或托盘按钮。
- Windows 全量回归、真实桌面链路、构建及隐私扫描通过。macOS CI 执行依赖安装、测试和应用构建，真实屏幕权限、多屏、全屏应用与快捷键列入实机验收。
