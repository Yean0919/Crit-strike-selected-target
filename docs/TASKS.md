## 首版默认值

- 停留三秒触发，允许五个物理像素内的位置抖动。
- 短暂漏检容错以 0.6 秒为基线，根据实际扫描周期调整，持续消失后重新建立目标。
- 每次稳定停留触发一次，明显移动后重新计时。
- 同屏最多播放四个效果，达到上限的目标等待空位。
- 默认使用全屏图片匹配，相同头像的不同出现位置独立处理。
- 截图仅在内存中使用，目标图片与配置保存在系统用户应用数据目录。
- 首版模组使用内置绘制器及 JSON 参数，不加载第三方可执行脚本。
