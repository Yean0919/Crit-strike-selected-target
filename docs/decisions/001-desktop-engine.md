# 001 全桌面识别与特效架构

## 决策

采用 Python 3.11、PySide6、OpenCV 和 MSS。截图与模板匹配在工作线程执行，GUI 线程管理跟踪状态、透明窗口和绘制。每个显示器单独捕获，物理像素转换为对应 Qt 屏幕的逻辑坐标。

头像识别使用多尺度相关匹配和颜色复核。裁切模板中心区域减轻圆角影响，低纹理模板拒绝导入。目标跟踪以身份、显示器和空间位置关联。默认启动后才检测。

简单效果采用 Qt 绘制器，JSON 模组调整参数。首版无需外部账号、模型接口或网络服务。Windows SetWindowDisplayAffinity 排除覆盖层，防止动画污染识别图像。

## 取舍

独立实现所需核心逻辑。参考公开项目的能力范围，避免引入授权不明确的代码或素材。当前仓库原有 LICENSE 保留并遵守。

模板匹配对头像更换、动态图片、严重遮挡及低分辨率存在限制。性能随显示器像素数及模板数量增加。检测周期可调整，工作线程不会堆积截图任务。
