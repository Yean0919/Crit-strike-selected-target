# 重击视觉反馈

## 目标

提高锤击和火花爆破的重量感，形成清楚的蓄力、快速打击、命中停顿和冲击消散过程。

## 行为与验收

- 锤击先抬起蓄力，再加速挥落。锤头落在目标中心，命中后短暂停顿并回弹。
- 锤体采用厚重金属块面，挥落有拖影，命中产生局部闪光、冲击环、裂纹与碎屑。
- 火花先收缩蓄能，再产生明亮爆心、放射爆闪、双层冲击波及带拖尾的飞散碎屑。
- 命中震动作用于特效覆盖层，颗粒轨迹保持时间连续。
- 既有 JSON 模组的颜色、大小、时长与次数继续生效。
- 动画末尾完全透明，预览与桌面播放使用相同绘制入口。
- 验证关键帧、重复绘制一致性、大小边界、动画结束和现有桌面操作链路。
