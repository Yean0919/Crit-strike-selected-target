# 2026-11-12 首版工程实现与验证

## 起点与范围

远端 main 初始提交为 `65b1f32`，初始仓库仅包含 README 和 Apache-2.0 LICENSE，工作区干净。用户指定独立项目目录及 GitHub 目标仓库，授权完成测试、隐私过滤后上传。

本轮实现 Windows 全桌面头像模板识别、三秒稳定触发、手动选点和三种参数化特效。使用 PySide6、OpenCV、MSS，直接依赖与开发环境版本已固定。沿用原有许可。

- `src/crit_strike/` 包含图像匹配、目标跟踪、配置持久化、Windows 显示器映射、捕获线程、透明覆盖层、主界面和裁剪界面。
- `src/crit_strike/mods/` 包含重锤、爆破、能量环三个程序绘制模组。
- `tests/` 覆盖缩放匹配、多目标、圆角、颜色复核、计时与漏检、坐标、配置异常、原子保存、模组校验、静态帧复用和 GUI 操作。
- `tools/` 包含桌面集成检查、Windows 便携包构建、源码及打包内容隐私检查。
- `.github/workflows/check.yml` 在 Windows runner 执行 lint、测试、Python 构建和源码隐私检查。
- `docs/`、`specs/` 记录需求、默认值、任务清单和模组使用方式。

## 实际发现与修复

1. Qt 在本机返回 EDID 屏幕名称，Win32 返回显示设备标识。改用屏幕原点和物理尺寸校验作为名称匹配失败后的映射方式，随后源码启动检查通过。
2. 第一版便携包启动时触发 PyInstaller 的 `pkg_resources` 间接依赖错误，缺少 `backports`。将应用运行不需要的 setuptools/pkg_resources 从打包依赖中排除，重建后的 EXE 冒烟启动退出码为 0。
3. 发现多屏主窗口排除区域需要按显示器裁切和独立传递，修正后添加 GUI 回归断言。
4. 二进制隐私扫描识别到 Qt TLS 解析器中的 PEM 分隔符。对二进制检查完整私钥正文与结束标记，保留源码中的分隔符检查及全部凭据检查。
5. 较慢扫描会让固定漏检间隔过短。跟踪容错以 0.6 秒为基线结合扫描周期调整，长时间捕获中断会清空计时状态。
6. 复核发现大窗口排除区域与小头像的 IoU 很低，修正为相交即排除，增加整窗排除回归断言，避免主窗口中的模板预览自行触发。

## 实机测量

Windows x64，单显示器 2560×1600，150% 缩放。使用程序生成头像，全桌面进行检测，未采集真实聊天内容作为测试资料。

- 三秒停留、持续停留去重、移动重计时、消失重现、手动点选、鼠标穿透和紧急停止均通过。
- 含 60 秒连续检测的那次测试首次触发耗时 4.515 秒，扫描均值 589.5 ms，P95 为 672.8 ms。三秒为最短稳定时间，实际触发时间包含采样与计算延迟。
- 特效开启前后，人工测试窗口的捕获像素平均绝对差为 0，验证特效层成功从捕获中排除。
- 连续检测 60 秒，工作集基线为 258134016 字节，结束为 259215360 字节，增长约 1.03 MiB。该检查验证短时稳定性。
- 同机存在其他活动窗口，画面持续变化。静态帧复用另外由自动化测试验证。

## 隐私处理

用户头像、配置、截图、构建日志、虚拟环境和构建产物均在 Git 忽略范围内。测试只生成合成头像。源码扫描检查常见凭据、私网服务地址、个人目录和用户数据文件。发布扫描检查 ZIP 内容、当前机器的个人路径及嵌入的 Python 代码。

原始检查报告与应用窗口截图保存在忽略的 `artifacts/`。仓库记录仅包含脱敏后的验证结果。

## 验证边界

- 多屏、负坐标和混合 DPI 的坐标计算已有自动化覆盖，物理多屏硬件尚未实测。
- 本轮真实桌面验证使用合成头像。真实头像库的误检率、动态头像及严重遮挡表现尚未量化。
- 60 秒连续检测通过，数小时运行和多模板高负载仍需更长时间验证。
- 首版交付便携 ZIP，使用系统提示音与内置绘制器。复杂模组、外部序列帧、自定义音频和安装器列入后续扩展。
